# Front End

React + Vite interface for the Medical AI Platform.

## Contents

- `src/` - React app, pages, reusable UI components, and API client helpers
- `index.html` - Vite entry page
- `package.json` - frontend scripts and dependencies
- `vite.config.ts` - Vite, React, Tailwind, and path alias config

## Run

```bash
npm install
npm run dev
```

The app expects the Node.js backend at `http://localhost:5000` by default.

Optional environment variables:

```bash
cp .env.example .env
```
